# Sample photos

Six tomato-leaf photos (256x256, unmodified) from the PlantVillage dataset, one per condition, so the
app can be tried without any photos of your own:

Hughes, D. P. and Salathé, M. (2015). *An open access repository of images on plant health to enable the
development of mobile disease diagnostics.* arXiv:1511.08060. Images obtained from the PlantVillage
Dataset mirror https://github.com/spMohanty/PlantVillage-Dataset.

**License note:** mirrors of PlantVillage state different licenses (CC0 1.0, CC BY 3.0, CC BY-SA 3.0,
CC BY 4.0). These photos are kept here with attribution; if that is a problem for your use, delete
this folder - the app works without it (the "Try a sample" row simply disappears).

`not_a_plant.jpg` is a synthetic picture generated for this project (no third-party content).
