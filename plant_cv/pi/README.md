# M.A.X.I.K. на Raspberry Pi

Пакет для робота: съёмка камерой, анализ растения на самом Pi или на сервере, проход вдоль грядки.

## Что нужно

- Raspberry Pi 4 или 5, лучше 4 ГБ памяти и больше;
- **64-битная** Raspberry Pi OS (Bookworm или новее). На 32-битной не заработает: нет onnxruntime;
- камера Raspberry Pi (Camera Module 3 или аналог), подключённая к разъёму CSI;
- интернет на время установки.

## Установка

Скопируйте архив на Pi (флешкой, через `scp` или скачайте) и выполните:

```bash
tar xzf MAXIK-pi-*.tar.gz
cd maxik
./install.sh
```

Скрипт сам поставит пакеты (попросит пароль sudo), создаст окружение, добавит команду `maxik` и в конце проверит модели на
примерах фото, показав время анализа на этом Pi. Займёт 5–15 минут. Запускать повторно безопасно.

Если Pi должен сам показывать веб-страницу (без отдельного сервера): `./install.sh --server`. Страница будет
доступна с любого устройства в той же сети по адресу `http://<адрес-pi>:5055/tomato` и запускается при включении Pi.

## Настройка

Файл `robot.conf` в папке `maxik`:

| Параметр | Что значит |
|---|---|
| `MAXIK_MODE=local` | анализ на самом Pi, сеть не нужна (по умолчанию) |
| `MAXIK_MODE=server` | фото отправляются на сервер `MAXIK_URL` |
| `MAXIK_MODE=fallback` | сервер, а если он недоступен, анализ на Pi; фото сохраняется и потом догружается (`maxik resend`) |
| `MAXIK_URL` | адрес сервера, например `http://192.168.1.50:5055` |
| `MAXIK_TOKEN` | токен сервера, если он запущен с `MAXIK_API_TOKEN` |

## Команды

```bash
maxik camera                          # пробный снимок -> camera_test.jpg
maxik photo --point row1-plant3       # снять растение и проанализировать; история ведётся по point
maxik photo --file leaf.jpg           # проанализировать готовое фото
maxik patrol --bed bed-1 --step 30 --frames 20   # проход вдоль грядки, камера смотрит вниз, кадр каждые 30 см
maxik resend                          # догрузить фото, накопленные без связи
maxik selftest                        # проверить модели на примерах
maxik server                          # вручную запустить веб-страницу на Pi
maxik help
```

К `photo` можно добавить показания датчиков: `--soil 0.4 --temp 24 --humidity 0.6`. Результат печатается в JSON,
его можно читать из программы робота.

## Что важно знать

- **На Raspberry Pi система ещё не проверялась.** `maxik selftest` в конце установки покажет реальное время.
  Анализ листа должен занимать доли секунды. Детекторам листьев и грядки на Pi 4 может понадобиться несколько
  секунд на кадр; если это слишком медленно для прохода, ставьте `MAXIK_MODE=server`.
- Экспозиция и баланс белого фиксируются перед каждым снимком, иначе цвета листьев «плывут» и оценка повреждения
  становится неточной.
- Детектор грядки обучен на наборе CropAndWeed (**только некоммерческое использование**).
- Это скрининг, а не лабораторный диагноз.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| `Needs 64-bit Raspberry Pi OS` | Переустановите систему: Raspberry Pi Imager → Raspberry Pi OS (64-bit) |
| `maxik camera` выдаёт ошибку камеры | Проверьте шлейф; `rpicam-hello --list-cameras` должна показать камеру |
| `Set MAXIK_URL` | Режим `server`/`fallback` без адреса: впишите `MAXIK_URL` в `robot.conf` или поставьте `MAXIK_MODE=local` |
| Веб-страница не открывается | `sudo systemctl status maxik-server`, журнал: `journalctl -u maxik-server -n 50` |
